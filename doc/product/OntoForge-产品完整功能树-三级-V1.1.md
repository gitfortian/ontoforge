## 一、为什么要维护这一份结构

本文件是**产品视角的完整功能树**，和原 AS-IS 实施视角清单有明确分工：**L1=8 个业务功能域；L2=V1.3 原定 F01–F29 共 29 组；L3=一个可观察用户操作/可信接口合同/可独立验收的能力**。L3 编号 `Fxx.yy`，不会覆盖历史 F01–F29，也不与 AS-IS 的 `OF-Fxx.xx.xx` 混淆。一个产品能力只有一个主归属；相关领域通过引用建立依赖，不重复计入。

状态解释：**已实现·限定环境**表示 GitHub 主线能够静态追到有限 Java/React 实现，不表示已跑本轮实机测试；**局部实现／待验证**表示已有相关代码、但合同/体验/企业化不完整；**规划／未实施**仅列目标产品能力，不承诺当前 MVP 必交付。测试、Windows UAT、灰度发布与运维 CI 另作为质量门禁管理，**不计为已完成产品业务功能**。

## 四、跨域依赖与“不是已实现”的显式边界

1. **Native 定义和实例分离**：F02 LinkType 的结构建模**不等于** F08 LinkBinding / F09 LinkFact；M2/M3 固定三表制造追溯不是 M8 通用关系。
2. **版本权威分离**：F04 本地 VALID 快照/摘要**不等于** SchemaRelease/Activation；F11 单次 query versionLock 不等于 F04 消费者兼容检查。
3. **源事实和查询结果分离**：F06/F08 来源映射可以静态验证，不证明来源业务时效；M7 resultSnapshot 是进程内短暂分页快照，不能冒充 F27 持久索引或源 MVCC 历史。
4. **Rule/Action 分离**：F14 的函数、规则、决策不得直接触发 F18 副作用；Action 成功回执仍须由 F10 真实业务状态和 F20 证据核验。
5. **安全贯穿，非单独按钮**：F19 对模型、对象、Link、查询/聚合、Agent 消费、Action 的独立授权分别生效；撤权必须连带终止继续读取。mvp-local 严格不是企业 IAM。
6. **知识证据/AI 只是待审事实来源**：F13 文档抽取与 F29 AI 建模都是候选，需要 F25 人工审查、F28 确定性门禁；不得生成无来源的已发布真相。
7. **Long-term 不等于 Core MVP**：当前下一纵向优先是 M8 通用关系、M9 来源质量、M10 版本/发布决策、M11 Studio；M12 Action、M13 Agent 按标准门禁；其余长期 F 功能保持 TO-BE，可按真实业务需求重排。

## 五、从产品功能树到实际交付的追溯

- **八域 F 编号权威**：本表保持 V1.3 原八域与 F01–F29。每个二级 F 在此只有一个主域；禁止为一个功能另起“后续能力”平行目录。
- **AS-IS 证据**：[原 125 条 M0–M7 代码盘点](../implementation/OntoForge-产品功能说明书-三级功能-V1.0.md)。它提供可查 Java/React 路径，不等于此完整产品树。按旧编号查询实施证据时回到该表。
- **旧编号零遗失迁移**：[125→216 追溯与边界/质量分类表](./OntoForge-ASIS到全产品功能树-追溯与分类-V1.1.md)：旧 125 条全部归档或关联，不因切换产品树而丢 M4–M7 已实施细节。
- **实施阶段关联**：[M5 #44](https://github.com/gitfortian/ontoforge/issues/44)、[M6 #45](https://github.com/gitfortian/ontoforge/issues/45)、[M7 #46](https://github.com/gitfortian/ontoforge/issues/46)、[M8 #47](https://github.com/gitfortian/ontoforge/issues/47)、[M9 #48](https://github.com/gitfortian/ontoforge/issues/48)、[M10 #49](https://github.com/gitfortian/ontoforge/issues/49)、[M11 #50](https://github.com/gitfortian/ontoforge/issues/50)、[M12 #51](https://github.com/gitfortian/ontoforge/issues/51)、[M13 #52](https://github.com/gitfortian/ontoforge/issues/52)、[M14 #53](https://github.com/gitfortian/ontoforge/issues/53)。Issue 的历史规划栏可能落后于合并状态，不能单独作为“未实现”的结论。
