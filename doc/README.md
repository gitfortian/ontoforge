## 产品定位

**通用本体核心 + 制造业及产业生态专业语义体系 + Agent 上下文与受控行动能力。**

底层引擎不绑定行业，行业特色通过基础本体、领域本体包、企业扩展和 Agent 能力包体现。平台连接现有 ERP、MES、PLM、QMS、WMS、EAM 等系统，不替代这些业务系统。
