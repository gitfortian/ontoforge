## 本次目标

根据用户上传的《DAMA-OMBOK第1–2章》（讲解资料）、GB/T 48000.4—2026《标准数字化 第4部分：协同制定要求》，以及本轮新增的 GB/T 48000.3—2026《标准数字化 第3部分：本体建模要求》，深度复盘原 V1.0，并形成可追踪的 V1.1 架构评审稿。**不覆盖 V1.0、不修改后端代码、不授权立即开发。**

## 改动清单

- 完整 V1.1 正式设计：延续 V1.0 的通用本体内核、制造业特色、Agent 受控行动定位，七功能域/23模块扩充为**八功能域/29模块**。
- 新增 **F24 术语语义共识、F25 协同审查、F26 本体对齐、F27 知识图谱工程、F28 质量门禁、F29 AI 辅助建模与反馈**，保留原 F01–F23 编号。
- 补充 Term/Concept/Type/Fact/Candidate 边界、ChangeSet/Review/QualityReport、候选与权威隔离、发布审批哈希、跨源查询与授权一致性。
- 新增“CRM/ERP/售后客户语义冲突→人工对齐→发布→影响分析→撤权验证”第三黄金故事及 P0–P4 Gate。
- 新增研究与 V1.0 差距分析，附资料页码与国标条款定位。
- 更新 doc/README.md 索引。
- **新增第3部分标准专项审核**：V1.1 增补第20–23章，形成 §5–9/规范性附录A 的条款差距追踪、强类型元模型/IRI/编译器与标准文档可选领域包设计。
- 新增 [GB/T 48000.3 逐条差距矩阵](doc/research/2026-10-14-GBT48000.3-本体建模要求差距矩阵.md)，并提出 **ADR-20–24**；不新增一级功能编号，不改变 P0–P4 总体路线。

## 重要证据边界

1. OMBOK 文件是用户提供的教学/讲解资料，其 DAMA 官方规范身份未独立核验，不作正式符合性声明。
2. **GB/T 48000.4—2026 是协同制定要求，不是第3部分《本体建模要求》**；仅借鉴其结构化数据、协同过程、角色权限、冲突检测和审查机制，不复制标准制定九阶段到本体平台。
3. GB/T 48000.3—2026 的适用范围是**标准数字化的标准本体**，附录A为规范性，附录B–D为资料性。我们的通用企业本体内核采纳其建模工程方法；若未来实现标准文件本体，使用独立 Standard Document Ontology Profile 做条款级验证，**不宣称当前通用平台符合第3部分**。
4. 所有新增技术选型/方案均处于评审或 POC 阶段，不声称已落地。
