对象读取

按已保存的 ObjectType 与 Binding 版本读取一个业务对象。对象身份、属性值和来源证据分开展示；读取失败不会伪装成空对象。

UX-Low 候选 · 不连接后端
原型说明：使用合成 supplier 数据演示状态与交互，不调用 API、不访问数据库、不代表 M6 已获实施授权。

恢复路径

结果下一步
404 OBJECT_NOT_FOUND检查键值或身份域
409 身份/属性冲突停止成功返回；核查来源重复记录
409 BINDING_SCHEMA_DRIFT返回 M5 修复映射，禁止同名列自动重绑
503 SOURCE_UNAVAILABLE保留输入并重试来源连接
429 QUERY_BUDGET_EXCEEDED收窄请求属性/修复来源数据，不放大服务端硬上限
