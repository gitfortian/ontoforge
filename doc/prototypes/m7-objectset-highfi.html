查询设计

按步骤定义查询范围。每次编辑都会使旧结果失效。

设计区
1对象与版本
已绑定
类型、对象身份和 Binding revision 必须匹配；版本不会自动漂移到“最新”。
2筛选条件
最多 8 个 AND 条件。字段类型决定可用操作符；NULL 与 MISSING 不会被当成空字符串或 0。
3排序
稳定排序
NULLS LAST；系统追加 ObjectRef 作为稳定平局排序键。
4结果列
投影
筛选和排序属性参与完整校验，但不必显示在结果列中。对象身份与来源证据始终保留。
5返回方式
结果快照同一次执行保持稳定
权限复核每页重新检查
6查询摘要
只读 AST
执行顺序Filter → Sort → Project → Page
范围Supplier · binding-20 / revision 1
筛选rating GT 4.0 AND active EQ true
证据snapshot-local-021 · freshness UNKNOWN
编辑查询将清除旧结果，避免混淆不同版本。
