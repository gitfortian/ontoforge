## 1. 本期唯一可交付的用户任务

用户已经在 Native Local Snapshot 定义 Equipment 与 InspectionLot 对象及 `equipment-inspections` LinkType，并使用 M5 完成两端的明确版本 Data Binding：

1. 在既有「本体建模 → 关系类型」入口选择已冻结 LinkType，进入 M8.1 关系绑定工作区。
2. 选择同一个 Local Snapshot、同一个 package 及允许 sourceId 下的**两端不可变** Object Binding revision，明确 FOREIGN_KEY 位于 SOURCE/TARGET 以及列；被引用 PK 身份列始终由服务端引用 M5 Binding.sourceKey，客户端不可手填 SQL/任意 PK/跨源连接。
3. 执行 FULL 只读验证，显示 FK 类型与基数、合法 NULL、精确空文本、可确认的非空孤儿、预算或授权错误；仅 FULL 且 `VALID` / `VALID_WITH_ORPHANS` 可提交不可变版本。
4. 创建或修订 LinkBinding：`expectedRevision` CAS、不可变 revision/digest、显式版本重开；创建使用 idempotencyKey，响应未知时先恢复原调用结果，不能重复造 head。
5. 由单个规范 ObjectRef 或受控有界 root ObjectSet，显式执行一段 `TRAVERSE`（OUT/IN，maxDepth=1）。返回去重对象/LinkFact、准确计数、双端 SourceReadRefs、三条 Binding 锁与完整质量/范围证据；IN 改遍历方向**不交换** LinkFact 本体 source/target。
6. 受控分页时持有**冻结的有界结果**，每页复核两端权限/来源/版本资格。准确零关联是 SUCCESS + COMPLETE + 0，相关 root 的可确认孤儿为 PARTIAL/KNOWN_SUBSET，其他错误 FAILED 且不返回旧对象/关系载荷。
7. 用户在 React 工作台可查看错误、修复、重新校验、保存、查询和返回上下文；开发完提供真实 PostgreSQL/HTTP/React Chromium 的一条黄金故事，不能仅复刻静态 HTML。

**严格不包含**：M8.2 桥表 M:N；M8.3 两跳；跨来源 JOIN；无界图遍历；持久 LinkFact 全量物化；CDC/外部 Action；正式 SchemaRelease/Index Generation 或企业行列授权的虚假宣称。

## 3. 八项维护者决策应明确接受的约束

| 决策 | 待正式裁定的实施合同 |

| G1 身份/版本 | 同一 package + LOCAL_SNAPSHOT + LinkType 最多一条 Head；明确 M5 SOURCE/TARGET revision、digest、identityDomainId，服务端不可隐式取 latest；保存含 CAS 和 create idempotency |
| G2 FK/质量 | 外键仅单列、同受控 PG、实际可读；依据 FK owner × cardinality 验证，M:N 保留下一阶段；FULL 才保存，VALID_WITH_ORPHANS 可保存但不等于整个查询答案 COMPLETE |

| G4 Query v2 兼容 | `local-link-binding-v1` 单独版本化，`local-query-v2/local-result-v2` 与旧 M7 v1 并存；唯一 rootSelector、一段 TRAVERSE、TARGET FILTER 和终结操作；不得无声放宽 schema/AST |

## 4. 生产单纵向 PR 的建议实施序列（不拆碎功能）

1. **冻结真实合同**：以 R2 已审定候选 JSON Schema 和本审查 G1–G8 为依据，生产化 local-link-binding-v1 / query-v2 / result-v2，反向合同测试证明 v1 原样可用；字段与 URL 在批准后最后核实，不猜 DTO。
2. **来源与不可变版本**：最新 main 确认 Flyway 编号，设计 Head/Revision/idempotency 持久化及历史只读；实现双端引用/快照校验、全量来源验证，服务器再核验资格后 CAS 保存；保存响应未知读幂等记录。
3. **真实 FK Join 与结果冻结**：同一源连接 read-only REPEATABLE_READ，基数、NULL、孤儿、预算及重复身份核验；冻结对象/LinkFacts/SourceReadRefs 和多端 versionLock；逐页当前资格重验/游标签名、撤权永久失效。
4. **API、权限、错误**：精确注册受控路由及认证规则；统一 400/401/403/404/409/410/422/429/503；错误附安全执行证据，失权不返回敏感来源细节。
5. **真实 React 工作台**：Native 关系类型进入配置、FULL→保存→查询分步、对象集合 OUT/IN 单根/有界 root、历史修订、CAS/UNKNOWN/漂移/撤权/超时恢复；未保存确认和移动端浏览器实际走通。
6. **闭环质量收口**：按下述矩阵跑所有真实测试，记录 head SHA/实际 run/screenshots；独立领域、安全、交互深度 Review 后再判定 Ready、merge、用户实际验收及 Release。
