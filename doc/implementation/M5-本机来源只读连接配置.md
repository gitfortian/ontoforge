# M5 本机来源只读连接配置

本配置用于 **local-pg-sandbox** 的本机 MVP / PostgreSQL 17 验收。它不是生产连接器，也不允许客户端提交 JDBC URL、主机、用户名或密码。

## 首次启用步骤

1. 先按既有方式启动 OntoForge 一次，不设置 **ONTOFORGE_BINDING_SOURCE_URL**。Flyway V7 会创建通用绑定表、合成表 **public.m5_supplier_source** 和只读组角色 **ontoforge_binding_reader**。应用在未配置来源连接时仍可启动，但 M5 来源 API 会 fail-closed 返回 **SOURCE_UNAVAILABLE**。
2. 停止应用。确认 PowerShell 中已设置管理员数据库连接变量；**DB_URL** 必须是本机 **ontoforge** 数据库，**DB_USERNAME/DB_PASSWORD** 为应用数据库管理账号。
3. 为来源账号设置一个本机专用密码，然后运行：

   ~~~powershell
   $secure = Read-Host "输入本机来源只读账号密码" -AsSecureString
   $env:ONTOFORGE_BINDING_SOURCE_PASSWORD = [System.Net.NetworkCredential]::new("", $secure).Password
   .\scripts\provision-m5-source-reader.ps1
   ~~~

   脚本创建/校准专用登录 **ontoforge_binding_login**，清理其直接表/序列授权和其他角色成员关系，再只授予 **ontoforge_binding_reader** 组。密码仅从环境读取，不写入仓库。

4. 启动应用前设置独立来源连接参数。来源 URL 与应用元数据 DB 指向同一个 loopback 本机数据库，但必须使用不同数据库账号：

   ~~~powershell
   $env:ONTOFORGE_BINDING_SOURCE_URL = $env:DB_URL
   $env:ONTOFORGE_BINDING_SOURCE_USERNAME = "ontoforge_binding_login"
   # 使用上一步输入的同一专用密码
   $env:ONTOFORGE_BINDING_SOURCE_ALLOWED_TABLES = "m5_supplier_source"
   ~~~

   若当前 PowerShell 会话没有保留密码，请重新输入并赋给 **ONTOFORGE_BINDING_SOURCE_PASSWORD**。启动 Spring Boot 后端。

## 安全边界

- 应用元数据连接和来源读取连接是两个独立 DataSource/JdbcTemplate。
- bindingSourceDataSource 使用 readOnly=true、连接初始化 default_transaction_read_only=on 和 3 秒查询超时；这些仅是纵深防护。
- PostgreSQL 登录账号 ontoforge_binding_login 不是 superuser、不能创建数据库/角色，且只继承 ontoforge_binding_reader 的 SELECT 权限。V7 首版只向该组授予 public.m5_supplier_source 的 SELECT。
- 来源别名固定为 local-pg-sandbox。首版要求 source URL 为 loopback 且与应用 DB 同一 ontoforge / ontoforge_test_* 数据库；拒绝 URL query options、fragment、内嵌用户名/密码和复用应用账号。
- 增加允许表时，必须同时调整服务端 allowlist、PostgreSQL 只读授权与负例测试。仅加入 allowlist 不会自动获得数据库读取权限。

## 验收证据

在应用 DB 管理账号下检查真实角色能力：

~~~sql
SELECT rolsuper, rolcreatedb, rolcreaterole
FROM pg_roles WHERE rolname = 'ontoforge_binding_login';

SELECT has_table_privilege('ontoforge_binding_login',
                           'public.m5_supplier_source', 'SELECT') AS can_select,
       has_table_privilege('ontoforge_binding_login',
                           'public.m5_supplier_source', 'INSERT') AS can_insert,
       has_table_privilege('ontoforge_binding_login',
                           'public.m5_supplier_source', 'UPDATE') AS can_update,
       has_table_privilege('ontoforge_binding_login',
                           'public.m5_supplier_source', 'DELETE') AS can_delete;
~~~

预期：rolsuper/rolcreatedb/rolcreaterole 均为 false，can_select=true，can_insert/can_update/can_delete=false。DataBindingIntegrationTest 还会使用独立来源连接尝试 INSERT，并验证 PostgreSQL 自身拒绝写入。不要将应用层 403 或 Java readOnly 设置替代该数据库证据。

## 当前边界

来源样本为 V7 创建的合成采购供应商数据。M5 只持久化来源映射、校验摘要和不可变 revision，不复制来源业务数据、不提供外部写回、不启用任意 SQL，也不代表生产连接器已交付。
